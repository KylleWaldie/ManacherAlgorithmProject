This project is coded in C# and takes an input from the user in the text box and outputs the longest palidrome in the string. It was programmed for CSCI-332 at Montana Tech University. I had to make a project that had a user interface that took the string and printed out an error messgae if the string was invalid or printed out the longest plaindrome in the string if the string was valid. It uses a lot of the .Net framework using forms for the user interface and uses the manacher algorithm to find the longest palindrome in the word that was input.
